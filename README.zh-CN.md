# WeChatTool

[English](README.md) | 简体中文

适用于 macOS 微信的插件，让收到的消息在发送者撤回后仍可在本机显示，并在支持的版本上提供撤回提醒。

WeChatTool 会创建一个启用插件的微信应用副本。原版应用保持不变，仍可继续使用。

## 使用 Mac 安装器

**使用打包好的安装器，无需终端命令、Python、Xcode，也无需自行编译。** 当打包版本可用时，请前往 [Releases](https://github.com/WeChatTool/WeChatTool/releases) 下载 **WeChatTool Installer**。标为 **Source code** 的压缩包仅包含源代码，不包含安装器应用。

你需要：

- 一台 Mac，以及支持其 macOS 版本和处理器的安装器。请根据处理器选择 Apple Silicon 或 Intel 版本；Universal 版本支持两者。可在 **苹果菜单 → 关于本机** 中查看处理器和 macOS 版本。
- 已安装官方微信 4.x，通常位于“应用程序”文件夹。
- 足够存放一份微信应用副本的可用磁盘空间。

### 1. 打开安装器

打开下载的压缩包或磁盘映像，然后打开 **WeChatTool Installer.app**。界面会根据 Mac 的首选语言显示英文或简体中文。

### 2. 选择微信并检查兼容性

安装器默认选择 `/Applications/WeChat.app`。如果官方微信安装在其他位置，请点击 **浏览**。请始终选择未经修改的官方应用，不要选择已经处理过的副本。

点击 **检查兼容性**。此操作只读取应用，不会修改微信或聊天数据。如果该版本不受支持，请继续使用原版应用。

### 3. 创建应用副本

请单独备份重要的聊天数据，并在创建副本前**正常退出微信**。点击 **创建微信副本**，选择保存位置。默认位置是个人文件夹中的 `Applications/WeChatTool-WeChat.app`。

如果该应用已经存在，请换一个名称。安装器不会覆盖已有应用或文件夹。等待创建完成；此过程会复制应用并在本机签名。

两个应用可能使用同一份聊天数据，**请勿同时运行**。应用副本并不是聊天数据备份，本机签名也可能影响对已有数据的访问或 macOS 权限。

### 4. 打开并验证

创建成功后，点击 **打开微信**，或点击 **在访达中显示** 找到副本，然后正常登录。

首次测试时，请让另一个账号发送一条新的文字消息，然后撤回。检查原消息是否仍然可见，以及支持的版本是否在同一会话中显示撤回提醒。重新打开会话，确认两者均可查看。在正式使用插件前，也请确认正常收发消息和查看已有聊天记录等功能。

需要启用插件时，请使用这个应用副本。打开“应用程序”文件夹中的原版 **WeChat.app**，则会运行官方安装版本。

## 撤回提醒

在支持的版本上，WeChatTool 会保留原消息，并在**同一会话中添加一条本地系统消息**。提醒使用微信撤回事件中的原有文字，包括事件提供的发送者名称，并附加“（已阻止本机撤回）”或“(recall blocked on this Mac)”。

微信会将提醒保存在本机的会话记录中，关闭并重新打开应用后仍可查看，不会发送给其他会话参与者。已有安装需要**使用更新后的安装器重新创建微信副本**，才能启用此功能。

## 兼容性

微信 **4.1.15（构建版本 270099）** 的 Apple Silicon 和 Intel 版本均已通过兼容性检查。原生代码测试已在 Apple Silicon 上运行，Intel 架构的测试则通过 Rosetta 运行。这不代表所有微信功能、消息类型或未来版本都能正常使用。

撤回提醒的适配已针对上述版本及构建号的两种处理器版本进行审查。**持久保存的撤回提醒仍属实验功能：目前通过独立测试应用验证，尚待在真实微信会话中确认效果。** 其他通过兼容性检查的微信版本可能仍能保留消息，但不会显示撤回提醒。

每次创建副本前，都应先检查已安装的微信版本，再通过测试消息验证实际效果。不支持微信 3.x、Windows 版或移动端。

## 更新

微信更新后，请打开安装器，选择更新后的官方应用，重新检查兼容性。使用新的名称创建副本，例如 **WeChatTool-WeChat-new.app**。不要将旧副本的配置用于新版微信。

启动新副本前，请先退出旧副本。在确认新副本正常工作之前，保留旧副本。此工具不会禁用微信的自动更新；生成的应用副本一旦更新，插件可能被移除或失效。

更新安装器时，请在 [Releases](https://github.com/WeChatTool/WeChatTool/releases) 有新版本可用后，下载适合这台 Mac 的打包版本。**请使用更新后的安装器重新创建微信副本，以启用撤回提醒等新功能。** 已有副本不会自动更新插件。

## 返回原版或卸载

退出生成的副本，然后从“应用程序”文件夹打开原版 **WeChat.app**。如果要移除插件，请在访达中**仅将生成的应用副本**移到废纸篓。不再需要安装器时，也可以删除 **WeChatTool Installer.app**。

请勿删除微信的聊天数据文件夹或容器目录。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 找不到安装器下载 | 可能尚未发布打包版本。从源代码构建需要下文列出的开发工具。 |
| macOS 无法打开安装器 | 确认下载的版本支持这台 Mac，并查看该版本的发布说明。 |
| 兼容性检查未通过 | 使用原版应用。当前版本的工具无法为该微信安装创建兼容的副本。 |
| 目标路径已存在 | 选择一个以 `.app` 结尾的新名称，或在访达中仅删除旧的生成副本。 |
| 副本无法启动、登录或显示已有聊天记录 | 退出副本并返回原版应用。不要通过删除数据库或重置账号数据来排查问题。 |
| 消息仍被撤回 | 确认打开的是生成的副本。可按下方可选步骤查看运行日志。 |
| 消息已保留，但没有撤回提醒 | 查看发生撤回的会话。请使用更新后的安装器重新创建副本；微信版本也必须支持提醒功能。 |
| 更新后插件失效 | 检查更新后的官方应用，并重新创建副本。 |

反馈问题时，请提供 macOS 版本、处理器类型、微信版本及构建版本，以及安装器显示的兼容性结果或错误信息。分享诊断输出前，请移除个人路径和标识信息。

## 从源代码构建（可选）

本节适用于希望使用命令行，或暂时无法获取打包版本的用户。你需要 **Python 3.10 或更高版本**，以及包含 `clang`、`make` 和 `codesign` 的 **Xcode 命令行工具**。以下命令行流程无需安装额外的 Python 包、使用管理员权限或修改系统完整性保护（SIP）。

检查开发工具：

```sh
python3 --version
xcode-select -p
```

如果尚未安装命令行工具，运行以下命令并等待安装完成：

```sh
xcode-select --install
```

下载源代码，然后在其目录中运行后续命令：

```sh
git clone https://github.com/WeChatTool/WeChatTool.git
cd WeChatTool
```

检查官方微信安装：

```sh
make analyze
```

查看结果中是否出现 `structurally-compatible`。这表示已安装的微信通过了检查，但尚未验证实际的消息行为。如果结果为 `unsupported`，请停止操作，继续使用原版应用。

退出微信，然后构建插件并创建副本：

```sh
make build
python3 -m wechattool prepare --output "$HOME/Applications/WeChatTool-WeChat.app"
```

成功时会输出 `prepared-and-signature-verified`。目标必须是尚不存在、以 `.app` 结尾的路径；已有文件和文件夹不会被覆盖。创建完成后不会自动启动微信。

打开副本，并按照上文步骤验证：

```sh
open "$HOME/Applications/WeChatTool-WeChat.app"
```

如果官方微信安装在其他位置，请在以下两个命令中指定相同的源路径：

```sh
python3 -m wechattool analyze --app "$HOME/Applications/WeChat.app"
python3 -m wechattool prepare \
  --app "$HOME/Applications/WeChat.app" \
  --output "$HOME/Applications/WeChatTool-WeChat.app"
```

如果本地仓库没有未提交的修改，可以这样更新 WeChatTool 并创建新副本：

```sh
git pull --ff-only
make analyze
make build
python3 -m wechattool prepare --output "$HOME/Applications/WeChatTool-WeChat-new.app"
```

维护者可参阅 [发布说明](docs/distribution.md)，了解如何打包独立安装器。

## 可选的命令行诊断

如需查看运行状态，请在打开副本**之前**，先在终端运行：

```sh
log stream --style compact --level info --predicate 'subsystem == "local.wechattool"'
```

- `active`：插件已启用。请用测试消息确认实际效果。
- `recall-notices-active`：此安装版本已启用撤回提醒。请撤回一条测试消息，并在该会话中查看提醒，确认效果。
- `initialized-no-image-matched`：插件正在启动过程中等待加载。仅出现此状态并不表示插件已成功启用。
- `late-image-refused`、`initialized-refused` 或匹配失败状态：插件在本次启动中未能启用。请返回原版应用，重新检查兼容性。
- `disabled`：插件在本次启动中已被禁用。

按 **Control-C** 停止查看日志。

如需在副本中临时禁用插件，请退出微信后运行：

```sh
WECHATTOOL_DISABLE=1 "$HOME/Applications/WeChatTool-WeChat.app/Contents/MacOS/WeChat"
```

此操作仅在本次启动中禁用插件，不会恢复副本原有的签名身份。

## 限制与隐私

- 插件只影响这台 Mac 上的显示，不会改变其他会话参与者或设备看到的内容。
- 你自己撤回的消息，以及从其他设备撤回的消息，也可能继续在本机显示。
- 插件无法恢复已经删除的消息，也无法恢复从未下载或已经不可用的媒体文件。
- 某些消息类型或微信功能的行为可能发生变化，不保证兼容未来版本。
- 为显示提醒，插件会在内存中临时处理撤回事件文字和会话标识，然后调用微信保存一条本地系统消息。插件不会直接打开聊天数据库，不读取普通消息正文或账号凭据，也不导出这些信息。插件日志仅包含启用情况和兼容性状态，不包含姓名、会话标识或消息文字。
- WeChatTool 是独立项目。生成的应用使用本机签名，不使用微信原发布者的签名身份。
